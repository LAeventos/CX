CX EXPERIENCE - RESERVA DE POWERBANK

Este site envia o formulário diretamente para:
Cxestacaoderecarga@gmail.com

COMO O ENVIO FUNCIONA
- O site usa o serviço FormSubmit para receber os dados do formulário e encaminhar por e-mail.
- O visitante NÃO precisa abrir Gmail, Mail ou Outlook.
- Na PRIMEIRA submissão, o FormSubmit envia um e-mail de ativação para Cxestacaoderecarga@gmail.com.
- Abra esse e-mail e clique no botão/link de confirmação UMA VEZ.
- Depois da ativação, as próximas reservas chegam normalmente no e-mail.

DADOS ENVIADOS
- Nome completo
- Telefone
- Nome do evento
- Local do evento
- Data do evento
- Número do powerbank (campo numérico com setas, de 1 a 40)

PUBLICAÇÃO NO GITHUB PAGES
1. Envie index.html, style.css, script.js e a pasta assets para o repositório.
2. Ative o GitHub Pages normalmente.
3. Faça uma reserva de teste.
4. Confirme o e-mail de ativação recebido na conta da CX.
5. Faça um segundo teste para validar a entrega final.

OBSERVAÇÃO
O FormSubmit é um serviço externo. Se futuramente você quiser que o envio seja feito por uma infraestrutura própria da CX, será necessário adicionar um backend/serverless (por exemplo, uma função em Vercel, Netlify ou Cloudflare) e um provedor de e-mail.
